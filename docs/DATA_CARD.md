# 데이터 카드

## 현재 상태

현재 저장소에는 실행 확인용 toy 자료와 공개 Train/Dev의 재배포 가능한
프롬프트, 사용자가 원문을 받기 위한 선택 정보, 모델 답변 본문을 포함하지
않는 평가 결과가 있습니다. AIME 문제 원문과 최종 평가용 비공개 자료는
포함하지 않습니다.

## 공개 자료의 구성

공개 Train은 1,760개, Dev는 880개 문항입니다. 출처, 고정한 상위 커밋, 파일별
라이선스 근거, 변환 과정과 내용 해시는 `data/sources/`와
`data/public-data.v1.json`, 고지 문구는 `THIRD_PARTY_NOTICES.md`에 공개합니다.
공개 자료의 구성은 비공개 최종 평가의 구성이나 대응 관계를 뜻하지 않습니다.

## 공통 32K 조건

세 평가용 모델 프로필은 모두 32,768 토큰의 전체 문맥 한도에서
평가되었습니다.
따라서 공개 Train/Dev와 최종 평가 결과로 계산하는 품질은 모두 해당 공통
조건에서의 결과입니다.

## 공개 자료와 최종 평가

참가자에게 제공하는 Train/Dev 자료는 프롬프트와 모델별 사전 계산 평가 결과를
별도 파일로 둡니다. 평가 결과에는 `score`, 생성 수, 모델 입력 토큰 합계와
모델 출력 토큰 합계만 포함합니다. 참가자는 이 값과 공개 비용 정책으로
Train/Dev의 모델별 비용을 계산하고 라우터 학습·검증에 사용할 수 있습니다.

공식 평가에서 참가자 컨테이너에 전달하는 라우터 실행 입력에는 문항별 평가
결과나 계산된 실제 비용이 없습니다. 공개 비용 정책과 평가 등급은 알려진
조건이므로 라우터 설계와 등급별 선택에 사용할 수 있습니다.

모델 답변, 추론 과정, 정답, 종료 사유, 실패 기록과 운영 오류는 제공하지
않습니다.

최종 평가 자료는 공개 Train/Dev와 분리해 비공개로 평가합니다. 대회 전에는
자료 자체나 구성을 공개하지 않습니다. 평가 스냅샷, 정답과 문항별 대응표는
접근을 제한한 운영자 저장소에 보관하며 공개 저장소나 참가자 실행 환경에
포함하지 않습니다.

## AIME 처리

AIME 자료 저장소의 라이선스 표시는 문제 원문의 재배포 권한을 자동으로
보장하지 않습니다. 저장소에는 AIME 문제문, 내려받은 캐시, 시험용 데이터
사본, 컨테이너 계층을 넣지 않습니다. 공개 Train/Dev에 포함하기로 검토를
마친 자료에 한해, 고정 출처와 예상 해시를 사용자가 직접 내려받아 정해진
형식으로 만드는 절차만 제공할 수 있습니다.

자세한 권리 분리는 [DATA_LICENSES.md](../DATA_LICENSES.md)를 참고하십시오.
